# Anonymous positioning — proof via artifact + result, not named authority

**Status:** accepted (supersedes the "founder proof: practitioner authority" framing in SPEC §1/§3)

Beontheloop ships with **no named author**. The Deck carries no byline and no bio slide; the landing page makes no personal-authority claim (no name, no "CTO @ Skyhost", no employer). Trust is anchored on the **work**, not the person:

- **The artifact** — the free Deck you're reading and the Harness Starter Kit's *actual files* (custom `CLAUDE.md`, ralph-loop script, skills, `agent_docs` templates), judgeable before you buy.
- **The result** — one measured, unattended ralph run (270 files / 59 min / exit 0; 95–99% task-fit).

**Why:** the original SPEC pinned the Pre-sell's trust to practitioner authority (a named CTO @ Skyhost). We chose anonymity instead — the deck should sell the *ideas* and the toolkit should sell itself on its contents and a concrete result. The cost is real: named authority is the single strongest trust lever for a cold-traffic Pre-sell, and we are giving it up. We accept that trade because the free Deck is already positioned as the trust engine ("the map"), and an artifact a buyer can inspect plus a measurable run is proof that does not depend on who built it.

**Boundary:** the generic word "founder" / "the builder" may still appear as an anonymous reference to whoever created the harness — what is removed is any *identifying* name, role, or employer. If a named identity is ever reintroduced, it reverses this decision and the Proof section + SPEC must be revisited together.
